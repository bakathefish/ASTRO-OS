# Vendored type for the asset generator

- Space Grotesk 400/500/700 (Florian Karsten), SIL Open Font License 1.1.
- JetBrains Mono 400/700 (JetBrains), SIL Open Font License 1.1.

Static TTFs as served by Google Fonts on 2026-09-06. They are used only when
`assetgen.py` renders the committed PNGs (wordmarks, installer slides and
previews); nothing on the ISO or in a package depends on them.
